# Feature Diagnostic Log Specification

## Purpose

Define how an AI agent must inspect this feature's diagnostic logs to verify correct behavior and identify corner cases.

## Expected Events

List the diagnostic events, state transitions, and outcomes expected from a correct run.

## Corner Cases

List the corner cases that must be distinguishable in the logs and the expected evidence for each case.

## Failure Evidence

List the log evidence that indicates incorrect behavior, incomplete execution, or an unsupported state.

## Verification Procedure

Describe the ordered checks the AI agent performs against the logs and the evidence required to conclude that the feature works correctly.
