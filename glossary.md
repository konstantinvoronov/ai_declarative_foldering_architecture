## Суффиксы

| Суффикс                | Что описывает                                                                                                                                        | Правила и особенности                                                                                                                                   |
|------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`Screen`**           | Полноценный экран                                                                                                                                    | • Имеет собственный `AppBar`.<br>• Создаётся через роутер.<br>• Возвращает результат через `Navigator.pop`.<br>• На экране **ровно один** `Controller`. |
| **`Sheet`**            | Компактный макет, показываемый внутри другого экрана **или** в модальном диалоге                                                                     | • «Экран-в-экране».<br>• Один `Controller` на sheet.                                                                                                    |
| **`Params`**           | Объект‑контейнер параметров                                                                                                                          | • Передаётся в `arguments` при навигации или при создании виджета.                                                                                      |
| **`Widget`**           | Переиспользуемый, независимый виджет                                                                                                                 | • Не зависит от `Bloc`/`Cubit`/`Controller`.<br>• Используется во многих местах.                                                                        |
| **`Layout`**           | Чистая композиция из `Row`/`Column`/`Stack` и `Padding`                                                                                              | • Не содержит внутренних виджетов, только размещение.                                                                                                   |
| **`View`**             | Виджет, зависящий от глобального presenter                                                                                                           | • Читает данные из presenter, но сам их не меняет.                                                                                                      |
| **`Cubit`**            | `Cubit` или `Bloc` экрана                                                                                                                            | • Назван так же, как экран.<br>• Создаётся сразу после навигации.                                                                                       |
| **`Repository`**       | Источник и кеш данных для UI                                                                                                                         | • Синглтон, доступный через DI (locator).                                                                                                               |
| **`Presenter`**        | Связующее звено между `Repository` и `View`                                                                                                          | • Может быть глобальным или локальным (указывать в комментарии).                                                                                        |
| **`UseCase`**          | SRP code который отвечает за последовтельность из нескольких простых операций его можно наследовать из другой фичи в то время как репозиторий нельзя | • Содержит одну или несколько операций прикладной логики.                                                                                               |
| **`NavigationFlow`**   | UX‑процесс, объединяющий несколько `Screen`                                                                                                          | • Сам не содержит виджетов.<br>• Состоит из набора роутов и кубита.                                                                                     |
| **Account`Managable`** | суффикс Managable у интерфейса который включает класс означает что этим классом управлет менеджер,                                                   | • Если классом управляет менджер значит этому классу запрещены горизонтальные зависимости (листен) и он должен .                                        |

## Приставки

| Приставка | Значение | Пример |
|-----------|----------|--------|
| **`App`** | Существует несколько вариантов виджета, выбираемых через factory‑конструкторы или `enum` (например `AppLayouts`, `AppButtonHeights`). | `AppButton`, `AppModalSheet` |

### Краткие правила

1. **Один экран — один контроллер.** Controller создаётся сразу после перехода.  
1. **Раутинг всегда идет через go_router.** 
2. **Виджеты без суффикса** живут только внутри своего экрана либо являются сторонними библиотечными.  
3. **Sheet** может жить как внутренний слой экрана или как модальный диалог.  
4. **NavigationFlow** описывает только UI‑логику (порядок шагов), но не бизнес‑логику.

> Если элемент не укладывается в словарь — пересмотрите его обязанности или обсудите новое правило с командой.
